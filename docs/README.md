# VisaPilot — итоговый комплект для реализации

25 октября 2026 года. Продуктовая идея финализирована после пяти раундов интервью. Подготовлены 11 пакетов реализации, готовые запросы Codex и план работы двух backend-разработчиков на четыре часа.

Код приложения в этой задаче не создавался: результат — конкретная документация для его реализации. Проверка актуальных визовых источников, первый AI-запрос, сборка и испытания выполняются в соответствующих пакетах; они не выдаются за уже пройденные.

## Зафиксированный результат

Внутренний локальный прототип с аккаунтами, общим архивом вымышленных паспорта/выписки/полиса, несколькими делами, персональными правилами и чек-листами для 12 стран, реальной обработкой документов, обоснованными замечаниями, двумя независимыми прогрессами, ручным маршрутом/транзитом Турции и ОАЭ, черновиком письма и хронологией.

Python/FastAPI, SQLite и закрытые локальные файлы. Один обслуживающий ноутбук; остальные — браузерные клиенты. Основной запуск через Python-окружение; Docker дополнительный. Новые расходы запрещены: AI через существующий Plus/Codex CLI при доступном лимите. Фронтендер отдельно делает сайт по Figma через Codex и подключает API; презентация также вне backend-пакетов.

Публичная эксплуатация, настоящие личные документы, оплата, внешняя почта, покупка билетов/полисов, автоматическая подача и персональный процент одобрения исключены из четырёхчасовой версии. Бизнес-модель после хакатона оставлена открытой по ответу пользователя.

## Статусы решений

- Подтверждено пользователем — прямой ответ в интервью.
- Принято в исходном отчёте — историческая граница, пока не изменена текущим ответом.
- Инженерное решение — конкретизация реализации агентом внутри согласованного объёма; не приписывается пользователю как дословный выбор библиотеки/формулы.
- Проверка реализации — действие, которое требуется выполнить при создании продукта; не является новым вопросом о продуктовой идее.
- Открыто для будущего — вопрос публичного продукта/бизнеса, не включённый в прототип.
