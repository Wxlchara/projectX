# ADR-0006 — направления, заявитель и демонстрационные документы

Дата: 25 октября 2026 года.

Статус: принято пользователем в раундах 2–3.

## Контекст

Исходный отчёт требовал 12 направлений, но не утверждал каждую страну. Полная поддержка детей, ВНЖ, иных гражданств и групп создаёт разные ветви правил. Для четырёхчасового внутреннего прототипа нужно явно зафиксировать поддерживаемый случай и документы.

## Решение

Поддерживаемые направления:

| Континент | Страны |
|---|---|
| Европа | Франция, Испания |
| Азия | Япония, Индия |
| Африка | Египет, ЮАР |
| Северная Америка | США, Канада |
| Южная Америка | Бразилия, Аргентина |
| Океания | Австралия, Новая Зеландия |

Для каждой страны предусматривается туристический сценарий в общем движке. Это утверждение географического объёма, а не новая проверка действующих визовых правил.

Заявитель — один совершеннолетний гражданин РФ, проживающий в РФ, с обычным загранпаспортом: биометрическим или небиометрическим. Цель — туризм. Второе гражданство и иностранный ВНЖ не входят в поддерживаемый случай. Фактическое место подачи определяется правилами сценария; проживание в РФ само по себе не означает, что любая страна принимает заявление в РФ.

Неподдерживаемый случай получает явное объяснение. Туристический чек-лист для взрослого не применяется автоматически к ребёнку, группе, работе, учёбе или иному гражданству.

На демо используются три типа полностью вымышленных документов с обозначением «образец»:

1. Страница загранпаспорта.
2. Банковская выписка.
3. Страховой полис.

## Последствия

- Нужны данные и проверяемые примеры по всем 12 направлениям, а не только карточки стран.
- Загружаемые образцы действительно обрабатываются; вымышленность данных не оправдывает подстановку заранее заданного результата по имени файла.
- Три поддерживаемых типа проверяются там, где соответствующее требование применимо. Банковская выписка и полис не становятся обязательными для любой страны только из-за присутствия в демо.
- Дополнительные пункты чек-листа могут требовать подтверждения пользователя без AI-проверки файла. Их статусы должны показывать способ подтверждения.
- Перечень типов документа не утверждает поддержку любого PDF, фотографии любого качества или произвольного банковского шаблона. Форматы, лимиты и проверяемые поля закреплены в [инженерных решениях](../engineering-decisions.md) и [заданиях](../implementation-plan.md).
- Поддержка настоящих документов и публичная политика персональных данных остаются за пределами этого решения.
