# ADR-0003 — граница четырёхчасового прототипа

Дата: 25 октября 2026 года.

Статус: принято пользователем в первом раунде интервью.

## Контекст

Команда состоит из четырёх человек. Один делает презентацию, второй — фронтенд; пользователь и Ваня — backend и остальные компоненты. Доступно четыре часа на реализацию с AI-агентами. Исходная концепция охватывает не менее 12 направлений, но включает и функции с неподтверждённым доступом к внешним сервисам.

## Варианты

1. Внутренний прототип всех 12 направлений с общим сквозным сценарием.
2. Тот же прототип с дополнительными обязательными реальными интеграциями.
3. Публичный запуск с реальными пользователями и документами.

## Решение

Пользователь выбрал первый вариант: «Внутренний прототип: все 12 направлений и описанный сквозной сценарий».

Сценарий: анкета → персональный чек-лист → проверка ограниченного набора документов → замечания → два прогресса → ручное событие по делу.

Реальные почтовые, билетные и консульские интеграции не входят в четырёхчасовой результат.

## Последствия

- Для всех 12 направлений нужен общий исполняемый механизм и данные; карточка страны не заменяет поддержку сценария.
- На момент этого решения перечень стран и набор документов ещё уточнялись; затем утверждены в [ADR-0006](0006-supported-scenarios-and-demo-documents.md).
- Поддержка маршрута не означает поиск продаваемых рейсов.
- Хронология показывает введённые события с происхождением, а не неподтверждённые официальные статусы.
- Публичное использование и обработка настоящих документов не следуют автоматически из выбора внутреннего прототипа.
- Должны быть проверены конкретные критерии готовности; это решение не является оценкой, что весь исходный отчёт можно реализовать за четыре часа.
