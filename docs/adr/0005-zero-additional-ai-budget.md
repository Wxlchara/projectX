# ADR-0005 — AI без новых расходов для локального демо

Дата: 25 октября 2026 года.

Статус: нулевой новый бюджет, интернет и использование существующего Plus подтверждены пользователем в раундах 2–3. Конкретный адаптер выбран агентом для внутреннего локального прототипа; его интеграция ещё не реализована.

## Контекст

Нужно сегодня показать работающий внутренний прототип. Есть действующая подписка ChatGPT Plus; новый API-бюджет исключён. Пользователь подтвердил наличие интернета на демо. Все используемые документы полностью вымышлены.

## Варианты

1. Обычный платный API — исключён пользователем из-за новых расходов.
2. Прямой Sign in with ChatGPT в приложении — официальный вариант для подходящего локального/open-source приложения, но требует отдельной OAuth-интеграции.
3. Локальный вызов уже авторизованного Codex CLI из Python — выбран для демо как более короткий путь.
4. Отдельная локальная языковая модель — требует проверки оборудования и скорости, не выбрана основным путём.

## Решение

- Python-backend вызывает Codex CLI как локальный процесс через отдельный адаптер; CLI использует вход через ChatGPT, а не платный API-ключ.
- Используется документированный `codex exec` со структурированным ответом по JSON Schema. Python повторно валидирует структуру.
- Извлечение PDF-текста/OCR, сравнение дат/полей, применение подтверждённых правил и расчёт прогресса выполняются локально. AI нужен для пояснений и черновиков; роль в извлечении свободного текста ограничивается контрактом.
- Одна доступная аккаунту модель выбирается и проверяется в начале реализации. Нельзя предполагать, что любая модель API доступна по подписке.
- Один одновременный AI-запрос, ограниченный вход, тайм-аут и повторное использование результата только для тех же входных данных сокращают расход лимита.
- При недоступности AI сохраняются локальные проверки и ручное подтверждение полей; генерация может дать явно помеченный шаблон. Приложение не подменяет живой анализ заранее записанным результатом.
- Никакой покупки кредитов, автопополнения, переключения на платный API или копирования авторизации в репозиторий не требуется и не разрешается этим ADR.

## Что реально проверено

- На текущем ноутбуке найден CLI `0.164.0-alpha.11.1`.
- `codex login status` вернул `Logged in using ChatGPT`.
- Документация подтверждает автоматизированный режим, повторное использование сохранённого входа и структурированный вывод.

Пробный AI-запрос не выполнен. Остаток лимита и скорость ответа не проверены. Первая проверка реализации — минимальный запрос и получение JSON без API-ключа; затем тот же путь проверяется на синтетических данных.

## Последствия

- Нет новых расходов в пределах существующего включённого лимита; это не безлимитная генерация.
- Разработка в Codex и показ AI-функций расходуют общий доступный лимит аккаунта. Нужно проверить остаток перед демо и сохранить рабочую локальную ветку.
- Основной запуск приложения — на ноутбуке с локальным входом CLI, через Python-окружение. Docker не должен задерживать демо из-за авторизации.
- Это решение для внутреннего показа на ноутбуках, а не утверждённая схема коммерческого/публичного AI-сервиса.
- Запуск CLI из Python не означает, что документы получают право давать ему команды. В контракте входные документы рассматриваются как данные; процесс ограничивается необходимыми правами и отдельной рабочей папкой.
