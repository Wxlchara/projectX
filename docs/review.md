# VisaPilot — журнал интервью и решений

25 октября 2026 года. Статус: пять раундов завершены, продуктовые границы финализированы. Технические детали закреплены в инженерной спецификации; проверки реализации не выдаются за выполненные.

## Основание работы

Текущий запрос: изучить полный отчёт, обсудить неутверждённые детали и выделить самостоятельные задания для двух участников, отвечающих за всё кроме frontend и презентации. Команда состоит из четырёх человек, реализация с AI-агентами планируется за четыре часа.

Исходный отчёт теперь хранится в [source](source/VisaPilot_Concept_and_Decisions.md) без изменений. Указание в нём о прошлой остановке разработки — история; текущий запрос разрешает эту работу над концепцией и заданиями. Само приложение в рамках интервью не создавалось.

## Раунд 1

**Пользователь подтвердил:** внутренний прототип всех 12 направлений и путь анкета → персональный чек-лист → ограниченная проверка документов → замечания → два прогресса → ручное событие. Реальные почтовые, билетные и консульские интеграции исключены из четырёх часов.

Оба backend-разработчика знают Python, при необходимости C++. Есть четыре ноутбука и ChatGPT Plus; демо локальное. Пользователь допустил Docker и поручил выбрать подходящий способ запуска.

**Инженерный выбор:** FastAPI, SQLite, один модульный backend вместо набора микросервисов, один обслуживающий ноутбук. Первоначальный приоритет Docker затем изменён с учётом локального AI-входа.

## Раунд 2

**Пользователь подтвердил:** новые расходы на AI не допускаются; сегодня нужен показ, а не эксплуатация. Фронтендер делает работающий сайт через Codex, используя Figma, и подключает API. На демо используются три типа полностью вымышленных документов: загранпаспорт, банковская выписка и страховой полис.

**Уточнение:** фраза «на Figma» не означает, что результатом останется только макет. Конкретный frontend-стек пользователь не сообщал; API не зависит от него.

## Раунд 3

**Пользователь подтвердил все 12 стран:** Франция, Испания, Япония, Индия, Египет, ЮАР, США, Канада, Бразилия, Аргентина, Австралия, Новая Зеландия.

**Заявитель:** один взрослый турист — гражданин РФ, проживает в РФ, имеет обычный биометрический/небиометрический загранпаспорт, без второго гражданства и иностранного ВНЖ. Для остальных случаев — явное объяснение границы поддержки.

**AI:** интернет на демо будет, используем существующий Plus через локальный Codex CLI.

**Фактически проверено:** CLI 0.164.0-alpha.11.1 найден; codex login status вернул Logged in using ChatGPT. AI-запрос не запускался; остаток лимита и скорость не проверены. Минимальный запрос включён в начало пакета 5. Основной запуск выбран через локальное Python-окружение; Docker дополнительный.

## Раунд 4

**Пользователь подтвердил:** сравнение 12 направлений, ручной маршрут/транзит, черновик письма, страховые даты/территория/сумма и ручная хронология. Покупка билетов/полисов, автоподача и подключение почты исключены.

**Транзит:** Турция и ОАЭ; остальные транзитные страны явно требуют проверки. Это утверждение покрытия, не фактическая проверка действующих норм.

**Пользователь отклонил предложение без аккаунта:** кабинет нужен для загрузки и хранения документов. Требование трактуется как сохранение оригиналов вымышленных файлов для повторного открытия. Оно заменяет предложенную одноразовую схему удаления после анализа. Добавлен пакет 11 с реальным входом и владением данными.

## Раунд 5

**Пользователь выбрал:** общий личный архив с привязками к делам. Один паспорт повторно используется в нескольких поездках; проверки рассчитываются отдельно.

**Готовность:** обязательные документы добавлены, ключевые поля сверены пользователем, применимые проверки пройдены и обязательные действия подготовки выполнены. Файл сам по себе пункт не закрывает; неизвестное обязательное условие сохраняет «нужна проверка». Это не подтверждение консульства.

**Бизнес-модель:** оставить открытой, сначала проверить пользу прототипа. Платежи на демо не подключаются.

## Что изменилось относительно исходного отчёта

- Команда уже есть: четыре участника с установленными ролями.
- Поимённо утверждены все 12 стран, заявитель, три типа синтетических документов и транзитный объём.
- Нужны реальные аккаунты и сохраняемый общий архив. Одноразовое удаление загруженного оригинала заменено для синтетического демо.
- Выбран Python/FastAPI/SQLite и существующий Plus через локальный CLI; новые расходы запрещены.
- Полностью описаны технические формулы/статусы, контракт, владельцы пакетов и порядок интеграции.
- Монетизация сознательно остаётся открытой после ответа пользователя.
