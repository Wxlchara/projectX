# VisaPilot — готовые запросы Codex

Каждый блок можно копировать целиком в Codex, открытый в общем репозитории. При работе на другом ноутбуке передайте весь каталог docs, включая source. Номера относятся к [implementation-plan.md](implementation-plan.md). Предполагается, что зависимости пакета уже выполнены или согласованы его контрактные фикстуры.

Общий контекст: внутренний прототип на четыре часа, два backend-разработчика, отдельные frontend и презентация, Python/FastAPI/SQLite, только синтетические документы, новые расходы запрещены. Исходный отчёт в source — исторический материал; текущие concept.md и review.md определяют принятый объём.
