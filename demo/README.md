# Вымышленные SAMPLE-документы

Это входные файлы для чтения PDF/OCR, **не AI-ответы** и не база визовых правил.
Имена, даты, суммы и организация VisaPilot вымышлены. Образцы не содержат
реальных персональных данных, номеров паспорта/счёта и официальных логотипов.
На каждой странице крупно указано SAMPLE / NOT A VALID DOCUMENT.

В documents лежат три комплекта (good/bad/corrected), по паспорту, выписке и
полису, каждый в PDF и PNG. Дополнительно: image-only scan_passport.pdf и
JPEG photo_passport.jpg. Всего 10 PDF, 9 PNG, 1 JPEG и manifest.json.
Обычные PDF содержат текст; скан содержит только растровую страницу.

Опорная поездка: 1–10 декабря 2026. good — комплект для будущего сценария
проверок, **без обещания достаточности для какой-либо страны**. bad содержит
истёкший паспорт, чужого владельца/старую дату выписки/неизвестную валюту и
полис на другую территорию с неподходящими датами. corrected меняет фактические
значения в содержимом. Детерминированные визовые проверки появятся в пакете 6
после схем правил Матвея. Извлекатель возвращает эти значения без оценки
визовой пригодности; ошибочный, но читаемый документ может быть extracted.

manifest.json описывает созданный контент только для разработки. Production
модули его не импортируют, не знают пути образцов и не принимают имя файла
как аргумент извлечения. Можно переименовать любой файл без изменения результата.

Пересоздание из корня:

```bash
.venv/bin/python -m pip install -r app/documents/requirements.txt -r demo/requirements.txt
.venv/bin/python demo/generate_documents.py
```

Это перезапишет только перечисленные генерируемые файлы в demo/documents.
Пользовательский архив local_data не затрагивается. Для загрузки через HTTP
и создания двух демоаккаунтов требуется каркас пакетов 1/11.
