# VisaMate

Сайт прототипа для подготовки туристической поездки. Название интерфейса — VisaMate.

- [Запуск сайта](frontend/README.md)
- [Концепция и границы продукта](docs/concept.md)
- [Контракт frontend и backend](docs/contracts.md)

Frontend работает самостоятельно в демонстрационном режиме и использует вымышленные данные. Когда backend из контракта станет доступен по `/api/v1` на том же адресе, сайт переключится на него.
